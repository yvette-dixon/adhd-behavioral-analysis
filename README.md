# ADHD Behavioral Analysis

## Project Overview

This project explores behavioral characteristics associated with ADHD symptoms in children using a dataset of approximately 6,500 observations and 32 variables.

## Research Question

Which behavioral characteristics are most associated with ADHD symptoms in children?

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Data Cleaning

* Checked for missing values and duplicate records
* Standardized column names and formatting
* Prepared a clean dataset for analysis

## Analysis Performed

* Descriptive statistics
* Exploratory data analysis (EDA)
* Correlation analysis
* Data visualization
* Grouping and filtering by ADHD diagnosis

## Key Findings

* Higher ADHD classifications were associated with lower focus scores.
* Difficulty organizing tasks showed a strong positive relationship with ADHD.
* Learning difficulties and anxiety levels were more common among higher ADHD groups.
* Daily phone usage showed little relationship with focus score.

## Visualizations Included

* Distribution of Daily Phone Usage
* Phone Usage vs. Focus Score
